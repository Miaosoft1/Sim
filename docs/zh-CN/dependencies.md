# 依赖核查（进行中）

框架自身拟采用 [MIT 许可证](../../LICENSE)，但不会改变依赖本身的许可。
独立恢复相邻公开源码树后，本地 NuGet 元数据显示解析出的 27 个直接及传递包均声明
MIT，包括新加入的 SignalR 客户端包；此计数不包含非 NuGet 条目的 .NET／ASP.NET
共享运行时。内容运行时使用 YamlDotNet 和依赖注入；测试及示例项目显式引用 MSTest
适配器、框架和 TRX 报告组件。

原先的 MSTest 元包会引入独立 Microsoft 许可的 CodeCoverage 扩展。它已不在当前
解析的依赖图中；旧构建目录仍可能残留文件，不得将其纳入发布产物。新目录中的
LocalCombat 发布结果不含 CodeCoverage 文件且 25 个场景通过，但这不能代替对
后续产物的核查。

测试适配器仍传递引入遥测扩展及 Application Insights。测试和示例项目排除该
扩展的构建资产，以避免自动注册遥测钩子；已检查本次独立生成的全部七个 Debug
运行器，未发现遥测／覆盖率注册。框架依赖型 Server 和 Console 发布目录不含测试、
Application Insights、遥测或覆盖率扩展程序集。此前 LocalCombat 发布结果仍包含
遥测扩展程序集，尽管钩子已排除。这不能证明
所有工具或第三方组件的隐私行为；不能假定 .NET CLI 的遥测设置会禁用其他遥测。

这只是本地元数据盘点，不代表已完成法律或隐私核查。任何对外发布前，仍需重新
检查最终依赖图、第三方声明、数据行为和实际发布产物。产品名称权利亦未核实；
本地实现及 MIT 源码许可不等于商标可用性核查。
